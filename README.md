# SAE 105 : Site vitrine du Vatican

Ce projet avait pour objectif de créer un site web touristique et adaptatif (*responsive*) dédié au Vatican, tout en utilisant des outils de travail collaboratif comme GitHub.

### Contenu du site
* **Accueil :** Présentation générale du Vatican.
* **Lieux :** Découverte des monuments incontournables.
* **Personnages :** Les figures historiques et marquantes.
* **Œuvres :** Les chefs-d'œuvre artistiques.
